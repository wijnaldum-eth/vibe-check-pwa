# Vibe Check App Flow Document

## Onboarding and Sign-In/Sign-Up
When a new user visits the Vibe Check Progressive Web App, they arrive at a clean landing page that briefly explains the purpose of the app and invites them to connect their cryptocurrency wallet. A prominent "Connect Wallet" button opens a RainbowKit modal where the user chooses among supported wallets such as MetaMask or WalletConnect. Once the user authorizes the connection in their wallet extension or mobile wallet app, the PWA receives the user’s public address and establishes a session. Returning users simply click the same button to reconnect their wallet and resume their session. Signing out is equally straightforward: a "Sign Out" option in the top navigation ends the session and returns the user to the landing page. Since authentication relies on wallet signatures rather than passwords, there is no traditional password reset flow; instead, the user reconnects their wallet to re-authenticate at any time.

## Main Dashboard or Home Page
After successfully connecting a wallet, the user lands on the main dashboard. The top of the screen features a header with the Vibe Check logo on the left and a small user avatar on the right. Below the header, the user sees a welcome message that displays their wallet address in shortened format. The main area of the dashboard is divided into cards: a mood input card prompts the user to record today’s sentiment in a single tap, a streak tracker card shows the number of consecutive days they have logged, and a network sentiment card summarizes the average mood of their Farcaster social circle. Further down, an interactive chart illustrates the user’s mood history over the past weeks, and a data table shows the consistency leaderboard across the entire user base. Navigation links in the header allow the user to move to detailed views of each feature without leaving the dashboard layout.

## Detailed Feature Flows and Page Transitions
When the user taps the mood input card on the dashboard, they are taken to a full-screen mood selection page. Here, simple icons representing various feelings invite the user to select exactly how they feel today. Once they make a choice, they tap a confirmation button and the app sends a request through a type-safe tRPC call to the Express API. The API writes the entry to PostgreSQL and updates the Redis cache for the leaderboard. The user then sees a success message and is smoothly returned to the dashboard, where the streak count and chart update in real time.

If the user clicks on the streak tracker card itself, a dedicated streak detail page opens. This page explains how streaks work, shows a calendar highlighting each day the user has logged, and lists upcoming reward milestones. From this page, the user can tap a button to share their streak on Farcaster. That action navigates to a special route that generates an Open Graph image of their streak and opens the share dialog for their Farcaster Frames app.

Clicking the network sentiment card leads to a social graph sentiment page. There, the app displays a breakdown of the user’s friends or followers fetched via the Neynar API. The page shows how many of them have logged moods today and the overall emotional tone of the network. A button labeled "Refresh Sentiment" triggers another tRPC call to fetch the latest data and update the display.

When the user achieves a major streak milestone, the Express API automatically initiates an NFT mint through the Alchemy SDK. The user sees a pop-up notification on the dashboard informing them that they have unlocked a badge. By tapping "View Badge," they navigate to the badge detail page, which shows the newly minted ERC-721 token image and provides a link to view it on a block explorer. This page also offers a button called "Share Badge," which brings up the Farcaster Frames share flow once again.

## Settings and Account Management
Users can access the settings page by clicking their avatar in the header and selecting "Settings." On this page, they can adjust their display name, enable or disable daily push notifications, and review permissions granted to their wallet connection. Although there is no traditional profile picture or email, the user sees their wallet address and can copy it to the clipboard. A toggle lets the user install the PWA to their device home screen if they have not already done so. A "Save Changes" button applies any new preferences and redirects the user back to the dashboard.

## Error States and Alternate Paths
If the wallet connection fails—because the user has no wallet extension or they reject the connection—the app displays a clear error message with guidance to install or unlock a supported wallet. When submitting a mood entry, if the network request times out or the user is offline, the app enters offline mode. It queues the mood entry locally and displays a banner notifying the user that their entry will sync once connectivity returns. In the event of an API error or an unexpected server response, the user sees an in-page alert that explains something went wrong and offers a "Retry" button. If the user attempts to log a second mood on the same day, the app prevents duplicate entries and shows an inline message explaining that today’s mood is already recorded.

## Conclusion and Overall App Journey
Starting with the easy wallet-based sign-in, the user is guided to the heart of Vibe Check on the dashboard, where they record their mood in a single tap, watch their streak grow, and see how their social network feels. Detailed pages provide deeper insights, allow sharing live Farcaster Frames, and reward consistent logging with NFT badges. Settings let users customize notifications and installation, while robust offline support and clear error messages keep them on track. In everyday use, the app becomes a simple ritual that encourages users to reflect on their feelings, engage with friends’ sentiment, and proudly share milestones in their crypto social network.
